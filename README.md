# Wilson Wu

[wuwwa.github.io](https://wuwwa.github.io/)

Personal portfolio built with Astro, JavaScript, and a canvas koi pond.

## Development

Requires Node.js 24 LTS.

```sh
npm ci
npm run dev
```

The development server runs at `http://127.0.0.1:4321/`.

```sh
npm test
npm run build
```

The static site is built to `dist/`. Push to `main` to deploy through GitHub Actions.
